# 0002. Conduit-centred scope

Date: 16 Sep 2026. Status: accepted.

**Context.** Other stations on the same CHORDS portal are not Conduit data, and download access to them is not guaranteed.

**Decision.** Use cases and validation sit at the Conduit station's footprint (Juja, Kiambu). Open satellite, reanalysis and forecast data may be combined with Conduit data. Other ground stations are optional extras only.

**Consequences.** Everything must run on the 8-day organiser sample. Longer portal history is used if it becomes available.
