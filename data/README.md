# data/

| Folder | Contents | In git? |
|---|---|---|
| `raw/organiser/` | The organiser GeoCSV files, unmodified | Yes (small, public, cite the DOI) |
| `raw/portal/` | Downloads from the CHORDS portal via `scripts/fetch_conduit_history.py` | No |
| `interim/` | Merged or cleaned intermediates | No (regenerated by the pipeline) |
| `reference/` | External reference pulls: Open-Meteo, NASA POWER, SoilGrids, CHIRPS | No |
| `processed/` | Pipeline outputs: `obs_qc`, `obs_hourly`, `health_daily`, `report.json` | No |

Never edit files in `raw/`. Record provenance in `docs/DATA_SOURCES.md`.
